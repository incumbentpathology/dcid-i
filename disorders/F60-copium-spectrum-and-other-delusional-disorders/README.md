# F60 · Copium Spectrum and Other Delusional Disorders

Disorders in which the patient’s account of its position is selected for comfort rather than supported by evidence. The spectrum runs from reassuring belief (copium maximum) to the failure of reasoning itself (delirium incumbentis).

Disorders added to this category by local editions take codes ending in `.8`, e.g. `F60.8x`. To propose a disorder for this edition, see [CONTRIBUTING.md](../../CONTRIBUTING.md).
