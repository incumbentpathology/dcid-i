# Cases

Case reports, one file per case, named `YYYY-MM-short-title.md`. Copy [`_template.md`](_template.md) to begin; [`2026-11-six-weeks-of-cash.md`](2026-11-six-weeks-of-cash.md) is a completed example.

Patients are recorded by type, never by name; see [CONTRIBUTING.md](../CONTRIBUTING.md#1-the-patient-is-a-type).
